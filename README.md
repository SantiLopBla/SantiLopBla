## Featured projects

### [Churn Prediction — End-to-End ML Pipeline](https://github.com/SantiLopBla/churn-prediction)

Built a complete machine learning pipeline to predict customer churn using the Telco Customer Churn dataset (7,043 records, 21 features). The project covers data ingestion, validation, feature engineering, model training (Logistic Regression, Random Forest, XGBoost), hyperparameter tuning with GridSearchCV, and full evaluation with metrics and visualizations.

**Stack:** `Python` `Scikit-learn` `XGBoost` `Pandas` `Matplotlib` `Seaborn`

---

### [Zara Sales — Exploratory Data Analysis](https://github.com/SantiLopBla/Zara-Sales-EDA)

Retail sales analysis project focused on uncovering patterns and business insights from Zara's product and sales data. Includes data cleaning, univariate and bivariate analysis, and visual storytelling.

**Stack:** `Python` `Pandas` `Matplotlib` `Seaborn`
